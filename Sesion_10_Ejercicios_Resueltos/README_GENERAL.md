## Ejecución

1. Extrae todo el ZIP.
2. En ejercicios 01 a 07, abre index.html de su carpeta. Cada uno tiene su styles.css.
3. En ejercicios 04 y 05, conserva también script.js.
4. En ejercicio 06, conserva la carpeta imagenes con sus seis SVG.
5. En ejercicios 08 a 12, abre respuesta.md.
6. Cada README contiene requisitos, solución y pasos de comprobación.

Solo necesitas un navegador moderno. No requiere instalar Node.js ni bibliotecas. Todo funciona sin Internet; Live Server es opcional.

## Interpretaciones y actividades de comparación

- Los resueltos conservan el diseño, los contenidos y parámetros del código de la guía, con soporte de teclado y movimiento reducido.
- Las actividades temporales de cambiar transition, transform-origin, orden, backface-visibility o eje se explican en los README, junto con el resultado esperado. Se mantiene la versión principal original.
- El menú usa JavaScript básico, una de las alternativas permitidas. El ícono hamburguesa usa la alternativa de clic.
- Las seis ilustraciones SVG de la galería son originales; el PDF no aporta imágenes obligatorias ni exige fotografías.
- Se documentan las elecciones de tamaño, velocidad y contenido cuando no están especificadas.
- Las precisiones técnicas sobre orden de transformaciones y conflictos de cascada se explican en los apartados correspondientes, manteniendo los requisitos prácticos.
- Para ver movimiento, desactiva temporalmente la preferencia de movimiento reducido del sistema. Las interacciones siguen disponibles si está activada.
